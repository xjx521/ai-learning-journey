# 第三~第五阶段学习指南：从「搭服务」到「调模型 + 做实验 + 集成系统」

> 🎯 写给刚完成第二阶段（Day 42）的你

---

## 一、学习方式的又一次根本转变

### 第二阶段（Web 开发）→ 第三~五阶段（AI 应用开发）

| 对比维度 | 第二阶段 | 第三~五阶段 |
|----------|----------|----------|
| **学习对象** | 协议 + 框架 + 工具 | **模型能力 + 数据链路 + Agent 编排** |
| **练习方式** | 搭服务、发请求、建数据库 | **调模型 API + 做实验 + 把零件集成为系统** |
| **调试方式** | 浏览器 F12 / API 工具 / 日志 | **打印中间过程（messages、tool_calls、检索结果）+ 实验对比** |
| **运行方式** | 启动服务器 → 访问接口 | 调云端 API → 观察「随机」输出 |
| **错误来源** | 网络、端口、协议、跨域 | **token 超限、API 限流、检索不到、幻觉、工具调用失败** |
| **知识特点** | 约定性高（RESTful 是规范） | **统计性高（同一个 prompt 输出不一定一样，要靠实验找规律）** |
| **成果形态** | Web API / 网站 | **AI 应用：能回答问题、能检索知识、能调用工具** |

### 🧠 核心心态转变

```
第二阶段：「我理解了这个协议/框架，能搭一个可访问的服务」
    ↓
第三~五阶段：「我理解了模型和数据链路，能造一个会思考的应用」
```

---

## 二、为什么作业模式要变：从「填空题」到「实验任务单」

### 第二阶段的 homework 是什么
填空题、填代码 → 有标准答案 → 练的是「语法和概念记得熟」

### 第三~五阶段为什么要换
1. **目标变了**：面试和简历考察的是「你能不能独立把系统搭出来」，不是「你会不会填」。填空题练不出独立性。
2. **知识变了**：AI 开发的输出有随机性（temperature）、有隐藏的中间过程（messages / tool_calls / 检索结果）。这些东西没有唯一答案，只有「你观察到了什么、为什么」。
3. **深度 5 关里的「能写」**：不看教程从零写。填空题恰恰是「看教程填空」，练不到这一关。

### 新的作业形态：实验任务单
每天一张「实验任务单」，包含：
- **动手任务**：没有标准答案，但有验收标准（跑通 / 看到效果 / 记录数据）
- **实验任务**：破坏性实验、对比实验——这是深度的来源
- **自测 5 关**：能讲 / 能写 / 能修 / 能答 why / 能扛边界
- **今日产出**：实验记录表 / 跑通截图 / git commit

> ⚠️ 重要：实验任务单**当天生成**，不提前一次性给你 20 张。
> 为什么？提前生成 = 一本新的静态教程 = 你又会「看教程」而不是「做实验」。
> 每天的任务按前一天的学习情况微调，才是「用到再学」。

## 三、第三~五阶段特有的学习技巧

### 1. 深度 5 关（每天对着自查）
| 关 | 问自己 |
|----|--------|
| 能讲 | 能不能用大白话讲给别人？（笔记里假装教一个同学） |
| 能写 | 关掉教程能不能从零写出来？ |
| 能修 | 报错能不能自己定位？（故意弄坏再修好） |
| 能答 why | 为什么这样设计？为什么这个参数？ |
| 能扛边界 | 空输入 / 坏输入 / 超长 / 断网，崩不崩？ |

### 2. 先手写再映射框架
每个框架技术（LangChain / LangGraph）都要经历：
```
手写实现（理解原理）→ 映射到框架（记类名、学语法）→ 产出框架版代码
```
既保住深度，又让你的简历能写 LangChain / LangGraph。

### 3. 实验驱动，不靠感觉
AI 开发最忌讳「我觉得这样改更好」。
每个实验要有：**变量 → 数据 → 结论**。比如：
- 分块实验：同一文档，chunk_size=200/500/1000，同一批问题，命中率各是多少？
- 检索优化：优化前召回率 vs 优化后召回率？
这些数据就是面试时你能拿出手的「企业级证据」。

### 4. 概念地图（每天填一行）
目录里有一份《概念地图.md》，列出了三个阶段的全部核心概念。
每学完一个，填一行：一句话解释 + 你的动手证据 + 落在哪个项目。
8/31 复盘时，它就是你的复习地图 + 面试提纲。

### 5. 破坏性实验（你的老本行）
Day 27 你就玩过：故意把 `default=0` 改成不满足验证规则，看它报错。
第三阶段继续这个习惯：故意用错 API key、故意让上下文超限、故意查库外问题——报错信息是你最好的教材。

## 四、工具链又变了

| 工具 | 用途 | 什么时候用 |
|------|------|-----------|
| **OpenAI SDK** | 调 LLM API（通义千问 / GLM 都兼容它） | Day 44 开始每天用 |
| **tokenizer** | 数 token、算成本 | 学 token 概念、调上下文 |
| **ChromaDB** | 向量数据库 | Phase 4 核心 |
| **LangChain / LangGraph** | 应用框架 / Agent 编排 | Phase 4 末 / Phase 5 |
| **Postman / Swagger** | 测自己写的 API（沿用） | 每次联调 |

> 💡 不用一次全学，遇到什么学什么。但 **OpenAI SDK 是 Day 44 就要用的**。

## 五、每日固定节奏（6-8 小时）
- 上午 2h：概念预习（读任务单里的材料）
- 下午 3-4h：动手 + 破坏性实验
- 晚上 1.5h：写笔记 + 填概念地图 + 自测 5 关
- 碎片 30min：LeetCode 1 题

## 六、和第二阶段的关系
你第二阶段学的**全部**都会用上：
- FastAPI + Streamlit → AI 应用的全栈骨架（Day39-40 模板直接升级）
- SQLAlchemy + MySQL → 对话历史、文档元数据
- JWT + 权限 → RAG 的文档权限控制
- Docker → 最后的部署
- 异步（async/await）→ 流式输出的基础

第二阶段不是白学的，它是你第三~五阶段的地基。
