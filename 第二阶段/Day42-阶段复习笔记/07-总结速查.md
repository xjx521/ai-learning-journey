# 🎯 面试高频考点总表

## 必问(背熟,张嘴就能说)

| 考点 | 一句话答案 |
|------|-----------|
| GET vs POST | GET 查(参数在 URL,幂等),POST 建(数据在 body,非幂等) |
| 401 vs 403 | 401 未登录,403 已登录但无权限 |
| 200/201/204 | 200 成功、201 创建成功、204 删除成功无内容 |
| JWT 是什么 | 三段式 Token(Header.Payload.Signature),签名防篡改 |
| 为什么 JWT 不存密码 | Payload 是 Base64 可解码,不是加密 |
| bcrypt vs MD5 | bcrypt 慢哈希自带盐,MD5 秒破 |
| Session vs Token | Session 服务器记状态,JWT 无状态 |
| CORS 是什么 | 浏览器同源策略,后端 CORSMiddleware 开门 |
| 中间件执行顺序 | 洋葱模型,先注册后执行 |
| 同步 vs 异步 | 异步用事件循环,一个 asyncio.run 入口 |
| 为什么异步要 await | 数据库/网络 IO 不阻塞,await 让出控制权 |
| commit vs flush | commit 真正持久化,flush 只是发 SQL 未提交 |
| PUT vs PATCH | PUT 全量替换,PATCH 部分更新(exclude_unset) |
| 镜像 vs 容器 | 模板 vs 实例(模具/披萨) |
| EXPOSE vs -p | EXPOSE 声明,-p 真映射 |
| 为什么 --host 0.0.0.0 | 否则容器外访问不到 |
| 依赖注入是什么 | Depends 自动运行依赖函数注入路由 |
| 前后端分离 | 前端只发 HTTP,后端管数据库 |

## 加分项(能讲出亮点)

| 考点 | 亮点 |
|------|------|
| SQL 注入 | ? 占位符永不拼字符串 |
| LEFT JOIN | 左表全保,N/A 用 NULL 补 |
| 索引 | B+树,最左前缀,EXPLAIN 验证 |
| N+1 问题 | 异步用 selectinload 解决 |
| 批量插入 | add_all + 一次 commit(快 ~221 倍) |
| expire_on_commit | 异步必配 False,防 MissingGreenlet |
| Pydantic v2 | model_dump() 不是 dict() |
| 统一错误格式 | exception_handler 全兜底,前端只看 success |
| host.docker.internal | 容器指回宿主机 |
| id 不连续 | 身份标识不是序号,不重排 |

## 冷门(知道就赢了)

| 考点 | 一句话 |
|------|--------|
| algorithms 必指定 | 防算法混淆攻击 |
| OAuth2PasswordRequestForm | 登录用表单不是 JSON |
| & \| ~ | SQLAlchemy 的 and/or/not 要加括号 |
| scalar vs scalars | 单个值 vs 多行 |
| datetime.timedelta | 算 exp 过期时间戳 |
| 三大范式 | 1NF 原子/2NF 完全依赖/3NF 无传递 |

# ⚡ 速查表

## HTTP 状态码速查

| 码 | 含义 | 记忆 |
|----|------|------|
| 200 | OK 成功 | 通 |
| 201 | Created 创建成功 | POST 后 |
| 204 | No Content 删除成功 | 无返回体 |
| 301 | 永久重定向 | 搬家 |
| 304 | 缓存未修改 | 用缓存 |
| 400 | 请求格式错误 | 客户端错 |
| 401 | 未认证 | 没登录 |
| 403 | 无权限 | 登录了没权限 |
| 404 | 资源不存在 | 找不到 |
| 405 | 方法不允许 | 用错方法 |
| 409 | 冲突(重复) | 已存在 |
| 422 | 参数校验失败 | Pydantic 抛的 |
| 429 | 请求太频繁 | 限流 |
| 500 | 服务器内部错误 | 后端 bug |
| 503 | 服务不可用 | 挂了 |

## Pydantic 常用验证器速查

|--------|------|
| min_length / max_length | 字符串长度范围 |
| gt / ge / lt / le | 大于/大于等于/小于/小于等于 |
| default | 默认值 |
| Field(pattern=...) | 正则匹配 |
| field_validator | 自定义校验函数 |
| model_dump(exclude_unset=True) | 只输出传了的字段(PATCH) |

## 异步 vs 同步速查

| 环节 | 同步 | 异步 |
|------|------|------|
| 引擎 | create_engine | create_async_engine |
| 连接串 | mysql:// | mysql+aiomysql:// |
| 会话 | Session / sessionmaker | AsyncSession / async_sessionmaker(expire_on_commit=False) |
| 路由 | def | async def |
| 查询 | db.query().filter().all() | await db.execute(select().where()) |
| 提交 | db.commit() | await db.commit() |
| 建表 | Base.metadata.create_all() | await conn.run_sync(...) |
| get_db | def + try/finally | async def + async with |
