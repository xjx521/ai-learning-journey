## 项目概述

### 为什么做这个项目？

你学了 FastAPI（后端）、Streamlit（前端）、SQLAlchemy（数据库）。现在把它们**串起来**，做一个真正的全栈应用。

同时，这个项目要能**复用**：它是一个「用户提问 → 保存记录 → 前端展示」的骨架，自带一个 **mock 的 LLM 接口**。下周进入第三阶段（LLM API）时，你只要把 mock 接口换成真正的 LLM 调用，就能变成真正的 AI 应用。

> 一句话：**做完这个模板，你以后每个 AI 项目都能基于它快速起步。**

### 核心架构

```
用户浏览器
   │
   ▼
Streamlit 前端 (localhost:8501)   ← 界面、输入、展示
   │  HTTP 请求 (requests)
   ▼
FastAPI 后端 (localhost:8000)     ← 业务逻辑、mock LLM、读写数据库
   │
   ▼
SQLite 数据库 (app.db)            ← 持久化提问记录
```

### 功能清单

| # | 功能 | 说明 |
|---|------|------|
| 1 | 健康检查 | `GET /api/health` 返回服务状态 |
| 2 | 提交提问 | `POST /api/prompts` 保存一条提问 |
| 3 | 查询记录 | `GET /api/prompts` 返回所有提问记录 |
| 4 | mock LLM | `POST /api/chat` 接收提问，返回一段模拟回答 |
| 5 | 前端界面 | Streamlit：输入问题 + 展示回答 + 历史记录列表 |
| 6 | 前后端联调 | Streamlit 通过 HTTP 调 FastAPI |

### 数据模型

`Prompt` 表（一条提问记录）：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer, 主键 | 自增 |
| text | String | 用户提问的内容 |
| response | String | 模拟回答（mock LLM 返回） |
| created_at | DateTime | 创建时间，默认当前时间 |

## 分步引导（闯关模式）

### Step 1 🔲 搭建 FastAPI 骨架 + 数据库

**目标**：能启动一个 FastAPI 服务，并能连上 SQLite。

- 安装依赖：`fastapi`、`uvicorn`、`sqlalchemy`、`pydantic`、`python-dotenv`、`streamlit`、`requests`
- 创建 `backend/database.py`：用 SQLAlchemy 配置 SQLite 连接（`sqlite:///./app.db`）
- 创建 `backend/models.py`：定义 `Prompt` 模型（按上面数据模型）
- `create_all()` 建表
- 启动 `uvicorn backend.main:app --reload`，访问 `/docs` 能看到自动化文档

### Step 2 🔲 基础 API 接口

**目标**：实现健康检查、提交提问、查询记录三个接口。

- `GET /api/health` → 返回 `{"status": "ok"}`
- `POST /api/prompts` → 接收 `{"text": "..."}`，保存到数据库，返回新记录
- `GET /api/prompts` → 返回所有记录（建议按时间倒序）

用 `/docs`（Swagger UI）测试这三个接口。

### Step 3 🔲 mock LLM 接口

**目标**：实现一个"假的 AI 回答"接口，模拟 LLM 调用。

- `POST /api/chat` → 接收 `{"text": "..."}`，返回一个模拟回答
- 模拟回答可以随便写，比如：`{"answer": f"你问的是：{text}，我是模拟回答。下周我会换成真正的 LLM！"}`

> 关键：这个接口的**输入输出格式**要和真 LLM 一致（接收文本、返回文本），这样下周换真 LLM 时前端不用改。

### Step 4 🔲 CORS + 环境变量

**目标**：让 Streamlit 前端能跨域调用后端。

- 用 `python-dotenv` 加载 `.env`
- 配置 `CORSMiddleware`，允许前端来源（如 `http://localhost:8501`）
- 把 `DATABASE_URL` 等放进 `.env`（不让提交到 Git）

### Step 5 🔲 Streamlit 前端

**目标**：用 Streamlit 做一个「提问 → 回答 → 历史」界面。

- 页面标题：`st.title`
- 输入框：`st.text_input` 让用户输入问题
- 按钮：`st.button` 提交
- 用 `requests` 调后端：`POST /api/chat` 拿回答，`POST /api/prompts` 保存，`GET /api/prompts` 拿历史
- 展示回答：`st.success` 或 `st.write`
- 展示历史：`st.dataframe` 或 `st.write` 列表
- 侧边栏：`st.sidebar` 放一个"刷新历史"的按钮或说明

### Step 6 🔲 前后端联调

**目标**：让前端能真实调用后端。

- 先启动后端（`uvicorn backend.main:app --reload`）
- 再启动前端（`streamlit run frontend/app.py`）
- 在页面输入问题 → 点提交 → 看到回答 + 历史记录出现
- 检查数据库 `app.db`，确认记录真的存进去了
