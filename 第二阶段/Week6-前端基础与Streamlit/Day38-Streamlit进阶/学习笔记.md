## 一、布局：把界面排整齐

### 1. 侧边栏 `st.sidebar`

把组件放进侧边栏，用 `st.sidebar.组件()`：

```python
import streamlit as st

st.sidebar.title("控制面板")
mode = st.sidebar.selectbox("模式", ["简洁", "完整"])
threshold = st.sidebar.slider("阈值", 0, 100, 50)

st.title("主页面")
st.write(f"当前模式：{mode}，阈值：{threshold}")
```

> 任何 `st.xxx()` 都可以写成 `st.sidebar.xxx()` 放进侧边栏。

### 2. 分栏 `st.columns`

一行里分几列：

```python
col1, col2 = st.columns(2)   # 分成两列，宽度一样
with col1:
    st.write("左边")
    st.button("左按钮")
with col2:
    st.write("右边")
    st.button("右按钮")
```

`st.columns(2)` 返回两个"容器"，用 `with col1:` 把组件放进去。也可以用 `st.columns([1, 3])` 指定宽度比例（左边 1 份、右边 3 份）。

### 3. 标签页 `st.tabs`

类似浏览器的多个标签页：

```python
tab1, tab2 = st.tabs(["介绍", "数据分析"])
with tab1:
    st.write("这是介绍页")
with tab2:
    st.write("这是数据分析页")
```

### 4. 折叠面板 `st.expander`

默认收起、点击展开的区块，适合放帮助/高级选项：

```python
with st.expander("点击展开更多"):
    st.write("藏在里面的内容")
```

### 5. 容器 `st.container`

一个"盒子"，可以用来组合/控制顺序：

```python
with st.container():
    st.write("这段在盒子里")
st.write("这段在盒子外")
```

## 二、表单 `st.form`：多个输入一起提交

**背景问题**：默认情况下，**每个控件改动都会触发脚本重跑**。如果你有好几个输入框，用户每改一个页面就跳一下，很烦。

**表单解决**：把多个输入放进 `st.form`，只有点"提交按钮"才一次性提交、重跑一次。

```python
with st.form("登录表单"):
    username = st.text_input("用户名")
    password = st.text_input("密码", type="password")
    submit = st.form_submit_button("登录")   # 表单内唯一的提交按钮

if submit:
    st.success(f"登录：{username}，密码已输入")
```

**关键点**：
- `st.form_submit_button()` 是表单内的**提交按钮**（不能用 `st.button`）。
- 表单内的控件在提交前不会触发重跑。
- 提交后，所有控件值一起可用。

> 类比：表单像"填写完一次性交卷"，而不是"每写一个字就交一次卷"。

## 三、文件上传 `st.file_uploader`

用户上传文件（图片、CSV、文本等）：

```python
uploaded = st.file_uploader("上传一个文件", type=["csv", "txt", "png"])
if uploaded is not None:
    st.write(f"文件名：{uploaded.name}")
    # 读取内容
    content = uploaded.getvalue().decode("utf-8")  # 文本文件
    st.text(content)
```

- `type=["csv","txt"]` 限制可上传的类型。
- 没上传时返回 `None`，所以要先判断 `if uploaded is not None`。
- 上传文件是 `UploadedFile` 对象：`.name` 是文件名，`.getvalue()` 是字节内容。

### 上传 CSV 并展示

```python
import pandas as pd
uploaded = st.file_uploader("上传 CSV", type=["csv"])
if uploaded is not None:
    df = pd.read_csv(uploaded)
    st.dataframe(df)
```

## 四、图表展示

### 1. 快速图表（传入数据即可）

```python
import pandas as pd

data = pd.DataFrame({"x": [1, 2, 3, 4], "y": [10, 20, 15, 30]})
st.line_chart(data)      # 折线图
st.bar_chart(data)       # 柱状图
st.area_chart(data)      # 面积图
```

### 2. Matplotlib 图（`st.pyplot`）

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots()
ax.plot([1, 2, 3], [4, 5, 6])
ax.set_title("我的图")
st.pyplot(fig)
```

### 3. Plotly 交互图（`st.plotly_chart`，可缩放/悬停）

```python
import plotly.graph_objects as go

fig = go.Figure(data=go.Scatter(x=[1,2,3], y=[4,5,6]))
st.plotly_chart(fig)
```

> 需要 `pip install plotly`。Plotly 图可交互，适合数据分析展示。

## 五、会话状态 `st.session_state`（重点）

### 为什么需要它？

**每次交互，Streamlit 都会重跑整个脚本，普通变量会被重置！**

```python
count = 0                       # 每次重跑都会被重置成 0
if st.button("加一"):
    count += 1
st.write(f"计数：{count}")       # 永远显示 1！
```

因为每次点按钮，脚本从头跑，`count = 0` 又执行了一遍。

**`st.session_state` 解决**：它像一个"跨交互存数据的抽屉"，脚本重跑时数据还在。

```python
# 初始化（只在第一次运行时执行）
if "count" not in st.session_state:
    st.session_state.count = 0

if st.button("加一"):
    st.session_state.count += 1

st.write(f"计数：{st.session_state.count}")
```

### 常见的初始化写法

```python
if "count" not in st.session_state:
    st.session_state.count = 0
```

`if "xxx" not in st.session_state` 判断"这个键存不存在"，不存在才初始化 —— 这样重跑时不会覆盖已有值。

### session_state 的典型用途

1. **计数器**（上面例子）
2. **购物车/记录列表**：记住用户点过哪些
3. **多页切换**：记住当前在哪个页面
4. **对话记录**：记住多轮聊天的上下文（AI 应用很常用！）

## 六、完整示例：一个"提问记录"小应用

把今天学的串起来（这也接近 Day 39-40 项目的雏形）：

```python
import streamlit as st

# 用 session_state 保存对话历史
if "history" not in st.session_state:
    st.session_state.history = []

st.title("提问记录")

# 侧边栏：控制
with st.sidebar:
    show_all = st.checkbox("显示全部")

# 输入
prompt = st.text_input("输入你的问题：")
if st.button("提交"):
    st.session_state.history.append(prompt)   # 记住本次提问
    st.success("已保存")

# 展示历史
if show_all:
    for h in st.session_state.history:
        st.write(f"- {h}")
else:
    if st.session_state.history:
        st.write(f"最新一条：{st.session_state.history[-1]}")
```

点几次"提交"，历史会一直累积——这就是 session_state 的威力。
