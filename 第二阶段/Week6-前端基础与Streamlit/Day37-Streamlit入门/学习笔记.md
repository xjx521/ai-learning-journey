## 一、Streamlit 是什么？（为什么它是 AI 开发者的神器）

**Streamlit 是一个用纯 Python 写 Web 界面的工具。** 你写 Python 脚本，运行时它自动生成一个网页。

```
你写：  st.title("欢迎")
        st.button("点我")
启动：  streamlit run app.py
得到：  ⬅ 一个漂亮网页，有标题、按钮
```

对比 Day 36 你学的"前端三大件"：
| 你要做的事 | 手写前端 | Streamlit |
|-----------|---------|-----------|
| HTML 结构 | 手动写标签 | 自动生成 |
| CSS 样式 | 手动写样式 | 自带主题 |
| JS 交互 | 手动写事件 | 自动处理 |
| 语言 | 要懂三种 | 只用 Python |

**为什么特别适合 AI 应用**：AI 应用的本质是"输入 → 模型/API → 输出"。Streamlit 让你几分钟就把"输入框 + 按钮 + 结果展示"搭起来，把精力放在 AI 逻辑上，而不是界面。

## 二、安装与启动

```bash
pip install streamlit
```

启动一个应用（假设你的文件叫 `app.py`）：
```bash
streamlit run app.py
```

启动后终端会显示一个本地地址（默认 `http://localhost:8501`），浏览器自动打开。

> 💡 小知识：Streamlit 默认端口 8501。改端口：`streamlit run app.py --server.port 8502`。

**运行原理（重要，理解它才能用好 Streamlit）**：
> **每次你点击按钮、拖动滑块等交互，Streamlit 会从脚本第一行开始，把整个脚本重跑一遍。**
> 所以你的代码是"自上而下执行"的，界面就是这个执行过程里渲染出来的。

放在后面思考：正因为它每次重跑，所以"跨越多次交互仍要记住的数据"要用 `st.session_state`（明天 Day 38 学）。

## 三、文本与标题组件（实验 1）

最常用的几个，用来展示文字：

```python
import streamlit as st

st.title("我的 Streamlit 应用")     # 大标题
st.header("这是一级小标题")          # 次级标题
st.subheader("这是二级小标题")       # 三级标题
st.write("这是普通文本")            # 万能输出：文本/数字/DataFrame/字典
st.markdown("**加粗** 和 *斜体*")   # 支持 Markdown 语法
st.caption("这是小字说明")         # 小字
```

- `st.write()` 是**万能**的，能输出字符串、数字、字典、DataFrame 等。
- `st.markdown()` 支持 Markdown 语法（`**加粗**`、`## 标题`、`- 列表` 等）。

## 四、输入控件（实验 2、3）

输入控件能让用户交互，Streamlit 会捕捉输入值并重跑脚本。

```python
name = st.text_input("你的名字", placeholder="请输入名字")  # 文本框
age = st.slider("年龄", min_value=0, max_value=100, value=18)  # 滑块
city = st.selectbox("城市", ["北京", "上海", "广州"])  # 下拉框
agree = st.checkbox("我同意")  # 复选框
```

**关键点**：控件的返回值就是用户输入的值。用 `=` 接住，后面就能用。

```python
st.write(f"你好，{name}！你 {age} 岁，在 {city}。")
```

### 常用控件速查表

| 控件 | 函数 | 返回什么 |
|------|------|---------|
| 文本框 | `st.text_input("标签")` | 输入的字符串 |
| 多行文本 | `st.text_area("标签")` | 输入的字符串 |
| 滑块 | `st.slider("标签", min, max, value)` | 数字 |
| 下拉框 | `st.selectbox("标签", 列表)` | 选中的一项 |
| 复选框 | `st.checkbox("标签")` | True/False |
| 单选 | `st.radio("标签", 列表)` | 选中的一项 |
| 按钮 | `st.button("文案")` | 点击时 True，否则 False |
| 数字输入 | `st.number_input("标签", min, max)` | 数字 |

## 五、反馈消息（实验 4）

给用户展示"成功/错误/警告"等提示：

```python
st.success("操作成功！")
st.info("这是一条提示信息")
st.warning("请注意，这里可能有问题")
st.error("出错了！")
```

分别对应：绿色✅ / 蓝色ℹ️ / 黄色⚠️ / 红色❌。

## 六、展示数据（实验 5）

AI 应用常要展示表格/字典，Streamlit 有专门组件：

```python
import pandas as pd

df = pd.DataFrame({
    "姓名": ["张三", "李四"],
    "分数": [90, 85],
})

st.dataframe(df)      # 可交互表格（可排序、滑动）
st.table(df)          # 静态表格（不可交互）
st.json({"response": "模型输出", "time": 0.3})  # JSON 展示
```

> `st.dataframe` 功能更强（可排序、可滚动），`st.table` 更简单静态。AI 应用展示结果常用 `st.dataframe`。

## 七、结合 FastAPI（实验 6）：让 Streamlit 调后端

这是本周最重要的"合体"——**Streamlit 当前端，FastAPI 当后端**。

Streamlit 里用 `requests` 调用 FastAPI 接口，把结果展示出来：

```python
import requests
import streamlit as st

# 后端 FastAPI 地址（Day 28 的 todo API 或 Day 39 项目）
API_URL = "http://localhost:8000"

# 用户输入一个问题
question = st.text_input("问点什么：")

if st.button("提问"):
    # 调用后端接口
    resp = requests.post(f"{API_URL}/api/chat", json={"text": question})
    result = resp.json()
    st.success(result.get("answer", "（无回答）"))
```

**核心流程**：前端收集输入 → `requests` 发给后端 → 后端返回 JSON → `st` 展示。

## 八、完整示例：一个"温度换算"小应用

把前面学的串起来：

```python
import streamlit as st

st.title("摄氏 ↔ 华氏 换算器")

c = st.slider("摄氏温度 °C", min_value=-50, max_value=100, value=25)

f = c * 9 / 5 + 32

st.write(f"华氏温度：{f:.1f} °F")

if f > 100:
    st.warning("好热！")
elif f < 32:
    st.info("结冰啦")
else:
    st.success("温度适中")
```

启动 `streamlit run app.py`，拖动滑块，看看温度和华氏值实时变化。
