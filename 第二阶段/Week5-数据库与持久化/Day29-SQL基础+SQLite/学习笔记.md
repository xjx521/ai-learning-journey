## 一、关系型数据库是什么？

```
Excel 表格         关系型数据库
─────────         ───────────
一个工作表          一张表（Table）
一行数据            一条记录（Row / Record）
一列标题            一个字段（Column / Field）
多张表关联          多表 JOIN
```

**类比理解：** 你之前用 Python dict 存待办事项，一个列表套多个字典。数据库就是把「内存里的列表」变成「硬盘上的永久文件」。

## 二、SQL 四大利器：CRUD

### 2.1 SELECT — 查数据

```sql
-- 基础查询：选所有列
SELECT * FROM todos;

-- 指定列 + 过滤 + 排序 + 限制
SELECT title, category, completed
FROM todos
WHERE category = '学习' AND completed = 0
ORDER BY created_at DESC    -- DESC 降序（新在前），ASC 升序（老在前）
LIMIT 10                     -- 只取前10条
OFFSET 20;                   -- 跳过前20条（分页的关键！）
```

**WHERE 常用运算符：**
| 符号 | 含义 | 例子 |
|------|------|------|
| = | 等于 | WHERE category = '学习' |
| != 或 <> | 不等于 | WHERE completed != 1 |
| > | 大于 | WHERE price > 50 |
| < | 小于 | WHERE id < 10 |
| >= | 大于等于 | WHERE age >= 18 |
| <= | 小于等于 | WHERE stock <= 5 |
| LIKE | 模糊匹配 | WHERE title LIKE '%Python%' |
| IN | 在列表中 | WHERE category IN ('学习', '工作') |
| BETWEEN | 范围 | WHERE price BETWEEN 10 AND 100 |
| IS NULL | 为空 | WHERE description IS NULL |

**LIKE 通配符：**
- `%` 匹配任意字符（包括空）：`'Py%'` 匹配 Python、Pycharm
- `_` 匹配单个字符：`'P_ton'` 匹配 Python

### 2.2 INSERT INTO — 插入数据

```sql
-- 插一条
INSERT INTO todos (title, description, category, completed, created_at)
VALUES ('学习 SQL', '完成Day29练习', '学习', 0, '2026-07-27');

-- 插多条（一次插入）
INSERT INTO todos (title, description, category, completed, created_at) VALUES
('学 HTTP', 'Day22内容', '学习', 1, '2026-07-24'),
('买牛奶', '全脂', '生活', 0, '2026-07-26');
```

### 2.3 UPDATE ... SET — 更新数据

```sql
-- 标记第1条为已完成
UPDATE todos
SET completed = 1
WHERE id = 1;

-- 同时更新多个字段
UPDATE todos
SET title = '买全脂牛奶', category = '买菜'
WHERE id = 2;
```

⚠️ **没有 WHERE 会怎样？** UPDATE 不带 WHERE 会更新表中**每一行**！这是新手最容易犯的错。

### 2.4 DELETE FROM — 删除数据

```sql
-- 删除第3条
DELETE FROM todos WHERE id = 3;

-- ⚠️ 危险操作：删全部！（慎用！）
-- DELETE FROM todos;   ← 不加 WHERE 就是自杀！
```

## 三、多表操作：JOIN

两张表：

```
users 表                        todos 表
┌────┬──────────┐              ┌────┬──────────┬───────────────┐
│ id │ username │              │ id │ user_id  │ title         │
├────┼──────────┤              ├────┼──────────┼───────────────┤
│  1 │ zhangsan │              │  1 │ 1        │ 学习 SQL      │
│  2 │ lisi     │              │  2 │ 1        │ 买牛奶         │
│  3 │ wangwu   │              │  3 │ 2        │ 写报告         │
└────┴──────────┘              └────┴──────────┴───────────────┘
                              todos.user_id → users.id  （外键关联）
```

**为什么要 JOIN？** 你想看"张三的所有待办"——不能只在 todos 表里找 user_id=1 吗？可以，但想知道"张三是谁"就得把两张表拼起来。

### INNER JOIN（内连接）

只返回两张表**都有匹配**的行：

```sql
SELECT u.username, t.title, t.completed
FROM users u             -- u 是 users 表的别名（简写）
INNER JOIN todos t ON u.id = t.user_id;
```

结果：

| username | title | completed |
|----------|-------|-----------|
| zhangsan | 学习 SQL | 0 |
| zhangsan | 买牛奶 | 0 |
| lisi | 写报告 | 0 |

> wangwu 没出现在结果里，因为他没有任何待办事项。INNER JOIN 只保留两边都有的。

### LEFT JOIN（左连接）

保留左表**所有行**，右表没有匹配的填 NULL：

```sql
SELECT u.username, t.title
FROM users u
LEFT JOIN todos t ON u.id = t.user_id;
```

结果：

| username | title |
|----------|-------|
| zhangsan | 学习 SQL |
| zhangsan | 买牛奶 |
| lisi | 写报告 |
| wangwu | **NULL** |

> wangwu 出现了！因为 LEFT JOIN 保证左表(users)每行都在结果里。右边没有匹配的填 NULL。

## 四、聚合函数

对一组数据进行统计计算：

```sql
-- COUNT(*) ：统计行数
SELECT COUNT(*) FROM todos;                    -- 共有几条待办
SELECT COUNT(*) FROM todos WHERE completed = 1; -- 完成了多少

-- SUM() ：求和
SELECT SUM(price) FROM orders;                  -- 订单总金额

-- AVG() ：平均值
SELECT AVG(age) FROM employees;                 -- 员工平均年龄

-- MAX() / MIN()：最大值 / 最小值
SELECT MAX(id), MIN(id) FROM todos;             -- 最大ID、最小ID

-- GROUP BY：分组统计
SELECT category, COUNT(*) as count, AVG(LENGTH(description)) as avg_len
FROM todos
GROUP BY category;                               -- 按分类统计数量和平均描述长度
```

**注意：** 用了 GROUP BY 后，SELECT 只能放分组的列或聚合函数。

## 五、SQLite 命令行实操

不用装任何东西——Python 自带 sqlite3 模块，配合 `sqlite3` 命令行工具。

### 启动 SQLite 命令行

```bash
# 创建/打开一个数据库文件（不存在就自动创建）
sqlite3 todos.db

# 进入后看到提示符：sqlite>
```

### 常用 `.dot` 命令

```sql
-- .open 切换到另一个数据库文件
.open newfile.db

-- .tables 查看所有表名
.tables
-- 输出：users  todos

-- .schema 查看建表语句
.schema todos
-- 输出：CREATE TABLE todos (id INTEGER PRIMARY KEY, title TEXT NOT NULL, ...)

-- .mode column 让输出对齐成表格（好看！）
.mode column
.headers on       -- 显示列名

-- .help 查看所有 .dot 命令
.help
```

### 完整操作演示

```sql
-- 1. 创建用户表
CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username TEXT NOT NULL UNIQUE,
    email TEXT,
    created_at TEXT DEFAULT (date('now'))
);

-- 2. 创建待办表（有外键关联）
CREATE TABLE IF NOT EXISTS todos (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    description TEXT,
    category TEXT DEFAULT '未分类',
    completed INTEGER DEFAULT 0,    -- 0=未完成，1=已完成
    user_id INTEGER REFERENCES users(id),
    created_at TEXT DEFAULT (date('now')),
    updated_at TEXT
);

-- 3. 插入数据
INSERT INTO users (username, email) VALUES ('zhangsan', 'zs@test.com');
INSERT INTO users (username, email) VALUES ('lisi', 'ls@test.com');
INSERT INTO todos (title, description, category, user_id) VALUES ('学习 SQL', 'Day29', '学习', 1);
INSERT INTO todos (title, description, category, user_id) VALUES ('买牛奶', NULL, '生活', 1);
INSERT INTO todos (title, description, category, user_id) VALUES ('写报告', NULL, '工作', 2);

-- 4. 查出来看看
.mode column
.headers on
SELECT * FROM users;
SELECT * FROM todos;

-- 5. JOIN 联表查询
SELECT u.username, t.title, t.category, t.completed
FROM users u
INNER JOIN todos t ON u.id = t.user_id;

-- 6. 退出
.quit
```

## 六、在 Python 中使用 SQLite

Python 标准库自带 `sqlite3`，不需要额外安装：

```python
import sqlite3

# 1. 连接数据库（文件不存在会自动创建）
conn = sqlite3.connect("todos.db")

# 2. 创建游标（用来执行 SQL）
cursor = conn.cursor()

# 3. 执行 SQL — 建表
cursor.execute("""
    CREATE TABLE IF NOT EXISTS todos (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        title TEXT NOT NULL,
        completed INTEGER DEFAULT 0
    )
""")

# 4. 插入数据（用 ? 占位符防注入！）
cursor.execute("INSERT INTO todos (title, completed) VALUES (?, ?)", ("学习 SQL", 0))
cursor.execute("INSERT INTO todos (title, completed) VALUES (?, ?)", ("买牛奶", 1))

# 5. 查询数据
cursor.execute("SELECT * FROM todos WHERE completed = 0")
rows = cursor.fetchall()   # fetchall 取所有行；fetchone 取一行
for row in rows:
    print(row)             # 每个 row 是一个元组：(id, title, completed)

# 6. 提交并关闭
conn.commit()      # 保存修改
conn.close()       # 关闭连接
```

**关键概念：**
- `conn = sqlite3.connect()` → 建立连接
- `cursor = conn.cursor()` → 创建执行工具
- `cursor.execute(sql)` → 执行 SQL 语句
- `conn.commit()` → 提交事务（不提交就不保存！）
- `conn.close()` → 关闭连接
