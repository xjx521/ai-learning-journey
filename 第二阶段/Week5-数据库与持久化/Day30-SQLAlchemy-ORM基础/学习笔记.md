## 一、什么是 ORM？

```
不用 ORM — 直接写 SQL：
    cursor.execute("SELECT * FROM todos WHERE completed = ?", (1,))
    # 需要写完整的 SQL 字符串，容易拼错

用 ORM — 像操作 Python 对象一样操作数据库：
    session.query(Todo).filter(Todo.completed == True).all()
    # 看起来就是 Python 代码！不需要写 "SELECT"
```

**ORM = Object-Relational Mapping（对象关系映射）**

类比理解：
```
Python 概念              ↔          数据库概念
─────────────                    ────────────
类 (class Todo)              →      表 (table todos)
实例 (Todo(title="学习"))     →       行 (row: id=1, title="学习")
对象的属性 (todo.title)       →        列的值 (column: title)
列表 [t1, t2, t3]            →         查询结果集
```

**SQLAlchemy 是 Python 最流行的 ORM 框架**，FastAPI 默认搭配使用。

## 三、定义模型类

### 3.1 最简单的模型

```python
from sqlalchemy import Column, Integer, String, Boolean, DateTime
from datetime import datetime
from sqlalchemy.orm import DeclarativeBase

class Base(DeclarativeBase):
    pass

class Todo(Base):
    __tablename__ = "todos"     # 对应的数据库表名

    id = Column(Integer, primary_key=True, autoincrement=True)    # 主键，自增
    title = Column(String, nullable=False)                          # 非空字符串
    description = Column(String, nullable=True)                     # 可选字符串
    category = Column(String, default="未分类")                      # 有默认值
    completed = Column(Boolean, default=False)                      # 布尔值
    created_at = Column(DateTime, default=datetime.now)             # 自动记录创建时间

    def __repr__(self):
        return f"<Todo(id={self.id}, title='{self.title}', completed={self.completed})>"
```

**Column 常用类型：**
| SQL 类型 | SQLAlchemy 类型 | Python 类型 | 说明 |
|----------|----------------|------------|------|
| INTEGER | `Integer` | `int` | 整数 |
| TEXT | `String` / `Text` | `str` | 文本（String可设长度） |
| BOOLEAN | `Boolean` | `bool` | 布尔值 |
| DATETIME | `DateTime` | `datetime` | 日期时间 |
| FLOAT | `Float` | `float` | 浮点数 |

**Column 常用参数：**
- `primary_key=True` → 设为主键
- `nullable=False` → 不允许为空（默认允许）
- `default=X` → 默认值
- `index=True` → 加索引（加速查询）

### 3.2 一对多关系：User + Todo

```python
from sqlalchemy import Column, Integer, String, ForeignKey, DateTime
from sqlalchemy.orm import relationship

class User(Base):
    __tablename__ = "users"

    id = Column(Integer, primary_key=True)
    username = Column(String, unique=True, nullable=False)
    hashed_password = Column(String, nullable=False)
    created_at = Column(DateTime, default=datetime.now)

    # ⭐ 关系声明：一个 User 有多个 Todo
    # back_populates 双向关联——在 Todo 那边也要反过来声明
    todos = relationship("Todo", back_populates="owner", cascade="all, delete-orphan")

class Todo(Base):
    __tablename__ = "todos"

    id = Column(Integer, primary_key=True)
    title = Column(String, nullable=False)
    completed = Column(Boolean, default=False)
    user_id = Column(Integer, ForeignKey("users.id"))  # ⭐ 外键指向 users 表的 id

    owner = relationship("User", back_populates="todos")  # ⭐ 反向引用
```

**关键概念：**
- `ForeignKey("users.id")` → 告诉数据库这个字段引用 users 表的 id 列
- `relationship()` → 让 Python 对象可以跨表访问（`user.todos` 拿到他的所有待办）
- `back_populates` → 双向关联开关
- `cascade="all, delete-orphan"` → 删除用户时，他下的所有待办也一起删（级联删除）

**一对多的直观理解：**

```
User:zhangsan ─┬─→ Todo:"学习 SQL"
               ├─→ Todo:"买牛奶"
               └─→ Todo:"写周报"

User:lisi   ───┬─→ Todo:"背单词"
               └─→ Todo:"交房租"
```

一个 User 对应多个 Todo ← 这就是一对多！

## 四、创建表和 CRUD 操作

### 4.1 建表

```python
from sqlalchemy import create_engine
from models import Base  # 你的模型类所在模块

engine = create_engine("sqlite:///test.db")

# 根据模型类自动建表（只创建不存在的表）
Base.metadata.create_all(bind=engine)
# 如果有 User 和 Todo 两个模型，会自动创建 users 和 todos 两张表
```

### 4.2 Session（会话）—— 操作的门户

```python
from sqlalchemy.orm import sessionmaker

SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
```

**Session 是什么？** 想象成「数据库事务的工作区」：
- 你做的所有修改先暂存在 Session 里
- `commit()` 才真正写入数据库
- `rollback()` 撤销所有修改

### 4.3 增删改查

```python
db = SessionLocal()

# ===== 新增 =====
new_todo = Todo(title="学习 SQLAlchemy", completed=False)
db.add(new_todo)                 # 放入 Session（还没写数据库）
db.commit()                      # 提交 → 真正写入
print(f"新建了 ID = {new_todo.id} 的待办")

# ===== 批量新增 =====
todos = [
    Todo(title="买牛奶", completed=False),
    Todo(title="写报告", completed=False),
]
db.add_all(todos)                # 批量插入
db.commit()

# ===== 查询所有 =====
all_todos = db.query(Todo).all()
for todo in all_todos:
    print(todo)                  # 调用 __repr__ 输出

# ===== 条件查询 =====
incomplete = db.query(Todo).filter(Todo.completed == False).all()
# 生成的 SQL: SELECT * FROM todos WHERE completed = FALSE

# 单条查询（不存在返回 None）
first_todo = db.query(Todo).first()
# 按 ID 精确查询
todo_by_id = db.get(Todo, 1)    # 推荐用法，比 filter 快

# ===== 更新 =====
todo = db.get(Todo, 1)
if todo:
    todo.title = "改个名字"       # 改属性
    todo.completed = True         # 另一个属性
    db.commit()                   # 注意：改了之后一定要 commit！

# ===== 删除 =====
todo = db.get(Todo, 2)
if todo:
    db.delete(todo)
    db.commit()

# ===== 关闭 =====
db.close()                       # 释放资源
```

## 五、高级查询技巧

### 5.1 过滤（Filter）

```python
# 等于
todos = db.query(Todo).filter(Todo.category == "学习").all()

# AND
todos = db.query(Todo).filter(
    Todo.category == "学习",
    Todo.completed == False
).all()

# IN（在列表中）
todos = db.query(Todo).filter(Todo.category.in_(["学习", "工作"])).all()

# LIKE（模糊搜索）— 用 like() 方法
todos = db.query(Todo).filter(Todo.title.like("%Python%")).all()

# IS NULL
todos = db.query(Todo).filter(Todo.description == None).all()
# 或写成：.filter(Todo.description.is_(None))
```

### 5.2 排序和分页

```python
# ORDER BY（倒序）
todos = db.query(Todo).order_by(Todo.created_at.desc()).all()

# LIMIT + OFFSET（分页）
page = 1
page_size = 10
todos = db.query(Todo).offset((page - 1) * page_size).limit(page_size).all()

# 也可以用 slice：.slice(start, end)
todos = db.query(Todo).offset(10).limit(20).all()
```

### 5.3 聚合函数

```python
from sqlalchemy import func

# COUNT
count = db.query(func.count(Todo.id)).scalar()     # scalar() 取第一个标量值

# SUM
total = db.query(func.sum(Todo.amount)).scalar() or 0

# AVG
avg = db.query(func.avg(Todo.score)).scalar()

# GROUP BY
results = db.query(
    Todo.category, func.count(Todo.id)
).group_by(Todo.category).all()
# 返回：[('学习', 3), ('生活', 2), ...]
```

### 5.4 关联查询（JOIN）

```python
# 方式1：joinedload（预加载，避免 N+1 问题）
from sqlalchemy.orm import joinedload

users = db.query(User).options(joinedload(User.todos)).all()
for user in users:
    print(user.username)
    for todo in user.todos:            # ✅ 不需要再查数据库
        print(f"  - {todo.title}")

# 方式2：join（类似 SQL JOIN）
results = db.query(User.username, Todo.title).join(Todo).all()
# 生成的 SQL：SELECT users.username, todos.title FROM users INNER JOIN todos ON ...
```

**⚠️ N+1 问题：** 如果不使用 joinedload，每次 `for todo in user.todos` 都会触发一次新的 SQL 查询。joinedload 一次性 JOIN 出来，性能提升巨大。
