## 项目概述

在 Day 28 的 Todo API 基础上，增加**用户系统**：

```
Day 28：一个所有人的共享待办列表（匿名）
       ↓
Day 35：每人有独立账号，只能管理自己的待办（有用户系统）
```

### 核心变化

| 变化                  | 说明                                    |
| --------------------- | --------------------------------------- |
| **新增 User 表**      | 存储用户名、密码哈希                    |
| **Todo 关联 user_id** | 每条待办属于一个用户                    |
| **注册 + 登录接口**   | POST /auth/register + POST /auth/login  |
| **JWT Bearer 鉴权**   | 所有操作需携带 Token                    |
| **权限控制**          | 只能改/删自己的待办                     |
| **CORS 中间件**       | 允许前端跨域访问                        |
| **环境变量**          | SECRET_KEY、DATABASE_URL 等从 .env 读取 |

### API 接口清单

| 接口         | 方法   | 路径                 | 权限                         |
| ------------ | ------ | -------------------- | ---------------------------- |
| 注册         | POST   | /auth/register       | 公开                         |

**需求：**

2. 配置数据库引擎和 Base
3. 定义 User 和 Todo 模型（一对多关系 + 级联删除）
4. 创建表并初始化

```python
from datetime import datetime
from sqlalchemy import create_engine, Column, Integer, String, Boolean, ForeignKey, DateTime
from sqlalchemy.orm import sessionmaker, DeclarativeBase, relationship
from dotenv import load_dotenv
import os

load_dotenv()  # ← 加载 .env 文件

# ========== 数据库配置 ==========
DATABASE_URL = os.getenv("DATABASE_URL", "sqlite:///./app.db")
engine = create_engine(DATABASE_URL, echo=False)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)

class Base(DeclarativeBase):
    pass

# ========== 模型定义 ==========

class User(Base):
    __tablename__ = "users"

    id = Column(Integer, primary_key=True, index=True)
    username = Column(String, unique=True, nullable=False, index=True)
    hashed_password = Column(String, nullable=False)
    created_at = Column(DateTime, default=datetime.now)

    todos = relationship("Todo", back_populates="owner", cascade="all, delete-orphan")


class Todo(Base):
    __tablename__ = "todos"

    id = Column(Integer, primary_key=True, index=True)
    title = Column(String, nullable=False)
    description = Column(String, nullable=True)
    category = Column(String, default="未分类", index=True)
    completed = Column(Boolean, default=False)
    user_id = Column(Integer, ForeignKey("users.id"), nullable=False)
    created_at = Column(DateTime, default=datetime.now)
    updated_at = Column(DateTime, nullable=True)

    owner = relationship("User", back_populates="todos")


# 建表
Base.metadata.create_all(bind=engine)
```

### Step 2 🔲 注册 + 登录接口

**目标**：实现用户系统的入口

**需要导入的模块：**
```python
from passlib.context import CryptContext
from jose import jwt, JWTError
from fastapi.security import OAuth2PasswordRequestForm
```

**需求：**

#### 2.1 POST /auth/register（注册）

```python
pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")
SECRET_KEY = os.getenv("SECRET_KEY", "change-me")
ALGORITHM = "HS256"
ACCESS_TOKEN_EXPIRE_MINUTES = 30
```

**接口行为：**
1. 接收 JSON 请求体 `{username, password}`
2. 验证：username 不重复、password 长度≥6
3. 用 `pwd_context.hash()` 对密码做 bcrypt 哈希
4. 写入 users 表
5. 返回 201 + `{"message": "注册成功"}`

**关键代码提示：**
```python
from pydantic import BaseModel, Field

class UserRegister(BaseModel):
    username: str = Field(..., min_length=3, max_length=50)
    password: str = Field(..., min_length=6)

@app.post("/auth/register", status_code=201)
def register(user: UserRegister, db: Session = Depends(get_db)):
    # 1. 检查用户名是否已存在
    existing = db.query(User).filter(User.username == user.username).first()
    if existing:
        raise HTTPException(status_code=400, detail="用户名已被注册")
    
    # 2. 哈希密码
    hashed = pwd_context.hash(user.password)
    
    # 3. 创建用户
    new_user = User(username=user.username, hashed_password=hashed)
    db.add(new_user)
    db.commit()
    db.refresh(new_user)
    
    return {"message": "注册成功", "user_id": new_user.id}
```

#### 2.2 POST /auth/login（登录）

```python
from datetime import datetime, timedelta
from typing import Annotated

OAuth2Schema = OAuth2PasswordBearer(tokenUrl="/auth/login")

def create_access_token(data: dict, expires_delta: timedelta | None = None):
    to_encode = data.copy()
    expire = datetime.now() + (expires_delta or timedelta(minutes=15))
    to_encode.update({"exp": expire})
    return jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)

@app.post("/auth/login")
def login(form_data: Annotated[OAuth2PasswordRequestForm, Depends()], db: Session = Depends(get_db)):
    # 1. 查用户
    user = db.query(User).filter(User.username == form_data.username).first()
    if not user or not pwd_context.verify(form_data.password, user.hashed_password):
        raise HTTPException(status_code=401, detail="用户名或密码错误")
    
    # 2. 签发 token
    access_token = create_access_token({"sub": str(user.id)})
    
    return {"access_token": access_token, "token_type": "bearer"}
```

**验证标准：**
- [√] POST /auth/register `{"username":"test","password":"123456"}` → 201
- [√] 再注册一次相同用户名 → 400（重复注册被拒绝）
- [√] POST /auth/login 用 OAuth2Form（username=ttest&password=123456）→ 200 返回 token
- [√] 密码输错 → 401
- [√] 检查数据库中 hashed_password 不是明文（是一长串 `$2b$...`）

### Step 3 🔲 Bearer Token 鉴权

**目标**：保护需要登录的接口

**需求：**

创建一个依赖注入函数 `get_current_user`，每个需要认证的接口用它：

```python
def get_current_user(
    token: Annotated[str, Depends(OAuth2Schema)],
    db: Session = Depends(get_db)
) -> User:
    """从 Bearer Token 中提取用户信息"""
    credentials_exception = HTTPException(
        status_code=401,
        detail="无法验证凭据",
        headers={"WWW-Authenticate": "Bearer"},
    )
    
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        user_id: str = payload.get("sub")
        if user_id is None:
            raise credentials_exception
        user_id = int(user_id)
    except JWTError:
        raise credentials_exception
    
    user = db.get(User, user_id)
    if user is None:
        raise credentials_exception
    
    return user
```

使用方式：
```python
@app.get("/todos/me")
def list_my_todos(
    current_user: Annotated[User, Depends(get_current_user)],
    db: Session = Depends(get_db),
    page: int = 1,
    size: int = 10
):
    # current_user 就是当前登录的用户！
    todos = db.query(Todo).filter(
        Todo.user_id == current_user.id
    ).offset((page - 1) * size).limit(size).all()
    total = db.query(Todo).filter(Todo.user_id == current_user.id).count()
    
    return {
        "data": [{"id": t.id, "title": t.title, ...} for t in todos],
        "pagination": {"page": page, "size": size, "total": total, "total_pages": math.ceil(total/size)}
    }
```

**验证标准：**
- [√] 不带 Token 访问 `/todos/me` → 401
- [√] 带无效 Token 访问 → 401
- [√] 带正确 Token 访问 → 只返回自己创建的待办
- [√] 两个不同用户分别登录，各自拿到不同的待办列表

### Step 4 🔲 Todo CRUD 绑定 user_id

**目标**：创建待办自动关联当前用户，查询只显示自己的

**改动点：**

1. **POST /todos** — 从 current_user 取 user_id
2. **GET /todos/me** — 过滤 current_user.id
3. **PUT/PATCH/DELETE /todos/{id}** — 检查 todo.owner_id == current_user.id

```python
# 创建待办：自动带上 user_id
new_todo = Todo(
    title=new_todo_in.title,
    description=new_todo_in.description,
    category=new_todo_in.category,
    user_id=current_user.id      # ← 关键是这行！
)

# 更新时检查所有权
if todo.user_id != current_user.id:
    raise HTTPException(status_code=403, detail="无权操作他人的待办")
```

**修改现有 TodoResponse 模型**，加上 `user_id` 字段：
```python
class TodoResponse(BaseModel):
    id: int
    title: str
    description: str | None = None
    category: str
    completed: bool
    user_id: int                # ← 新增
    created_at: str
    updated_at: str | None = None
```

**验证标准：**
- [ ] 用户A登录后创建待办 → 用户B登录后看不到
- [ ] 用户A尝试 PUT /todos/999（用户B的待办）→ 403 禁止
- [ ] 用户A PUT /todos/1（自己的）→ 200 成功
